# Radar panel: Privacy Policy and Terms of Use

Effective date: November 11, 2026

## 1. What this software is

The Radar panel is a personal tool. It runs on its owner's single computer and can be opened only from that computer. It has one user: its owner. It is not distributed, not offered to other people, and not operated as a service.

## 2. YouTube API Services

The panel uses YouTube API Services: it receives a list of links to public videos through the YouTube Data API.

- By using the panel, the user agrees to be bound by the YouTube Terms of Service: <https://www.youtube.com/t/terms>.
- Data processed by Google is subject to the Google Privacy Policy: <http://www.google.com/policies/privacy>.

## 3. What user information the panel collects

None. The panel has no accounts, no sign-up and no sign-in. It does not ask anyone to sign in to a Google or YouTube account, does not request user authorization, and does not receive any data that requires such authorization. It does not access, collect or store names, email addresses, watch history, subscriptions or any other information about people.

## 4. What data the panel receives through the API

The panel sends one kind of request: a search for public videos by the name of a game. The request is made with the panel owner's API key. Only four fields of each video found are stored:

- video ID;
- title;
- channel name;
- publication date.

The panel does not request or store statistics, descriptions, thumbnails, comments or the videos themselves.

## 5. How this data is used and with whom it is shared

The stored fields are shown to the owner on one page of the panel, as a list of links to the videos on the YouTube website, with YouTube named as the source. They are not used anywhere else: the panel does not calculate anything from them and does not build summaries or new metrics out of them.

The data is not shared with anyone: not with other people, organizations, programs or services, inside or outside. The panel does not publish or sell it. The panel shows no advertising, and no third party serves any content in it.

A video opens on the YouTube website through an ordinary link. From that point on, the terms and policies of YouTube and Google apply.

## 6. Cookies and information on the device

The panel is a local page in a browser on the same computer. To work, the browser keeps the panel's own technical session data (for example, a technical cookie that protects forms). This data does not leave the computer and is not used for tracking. Usage statistics collection is turned off in the panel. No third party gets access to information on the device or places cookies on it through the panel.

## 7. How long data is kept and how to delete it

Each stored video record is deleted automatically no later than 30 calendar days after the video was found. The owner can delete all records earlier at any time. If the panel stops using YouTube API Services, all data received through them will be deleted.

The panel stores no information about people, so there is nothing to delete at anyone's request. If you nevertheless believe the panel stores data about you, write to the contact in section 9, and such data will be deleted within 7 calendar days.

The panel does not use data that requires a Google user's authorization. Permissions granted to any application can be reviewed and revoked on the Google security settings page: <https://security.google.com/settings/security/permissions>.

## 8. API key

The API key belongs to the panel's owner, is kept only on the owner's computer, and is not shared with anyone.

## 9. Contact

Questions and complaints about privacy: <pupermanchik@gmail.com>

## 10. Changes

If the panel starts to receive or use data in any way not described here, this document will be updated before such use begins, and the date at the top will change.
