# Панель «Радар»: политика конфиденциальности и условия использования

Действует с: 11.11.2026

## 1. Что это за программа

Панель «Радар» — личный инструмент. Он работает на одном компьютере своего владельца и открывается только с этого компьютера. У панели один пользователь — её владелец. Панель не распространяется, не предлагается другим людям и не работает как сервис.

## 2. YouTube API Services

Панель использует YouTube API Services: через YouTube Data API она получает список ссылок на публичные видео.

- Пользуясь панелью, пользователь соглашается соблюдать Условия использования YouTube: <https://www.youtube.com/t/terms>.
- К данным, которые обрабатывает Google, применяется Политика конфиденциальности Google: <http://www.google.com/policies/privacy>.

## 3. Какие сведения о пользователях собирает панель

Никаких. В панели нет учётных записей, регистрации и входа. Она не просит входить в аккаунт Google или YouTube, не запрашивает авторизацию пользователя и не получает данных, доступ к которым требует такой авторизации. Имён, адресов почты, истории просмотров, подписок и любых других сведений о людях панель не получает, не собирает и не хранит.

## 4. Какие данные панель получает через API

Панель отправляет один вид запроса — поиск публичных видео по названию игры. Запрос идёт с ключом API владельца панели. Из ответа сохраняются только четыре поля каждого найденного видео:

- номер видео;
- название;
- название канала;
- дата публикации.

Статистику, описания, картинки, комментарии и сами видео панель не запрашивает и не хранит.

## 5. Как эти данные используются и кому передаются

Сохранённые поля показываются владельцу на одной странице панели — списком ссылок на видео на сайте YouTube, с указанием, что источник — YouTube. Больше они нигде не используются: панель ничего по ним не считает, не строит из них сводок и новых показателей.

Данные никому не передаются — ни другим людям, ни организациям, ни другим программам и сервисам. Панель их не публикует и не продаёт. Рекламы в панели нет; третьи лица не размещают в ней никакого содержимого.

Видео открывается на сайте YouTube по обычной ссылке. С этого момента действуют условия и политика самого YouTube и Google.

## 6. Куки и данные на устройстве

Панель — локальная страница в браузере на том же компьютере. Для её работы браузер хранит служебные данные сеанса самой панели (например, служебный куки защиты форм). Они не покидают компьютер и не используются для слежения. Сбор статистики использования в панели отключён. Третьи лица не получают доступа к данным на устройстве и не размещают на нём куки через панель.

## 7. Сколько хранятся данные и как их удалить

Каждая сохранённая запись о видео удаляется автоматически не позднее чем через 30 календарных дней после того, как видео было найдено. Владелец может удалить все записи раньше в любой момент. Если панель перестанет пользоваться YouTube API Services, все полученные через них данные будут удалены.

Сведений о людях панель не хранит, поэтому удалять по чьей-либо просьбе нечего. Если вы всё же считаете, что панель хранит данные о вас, напишите по адресу из раздела 9 — такие данные будут удалены в течение 7 календарных дней.

Панель не использует данные, для доступа к которым нужно разрешение пользователя Google. Разрешения, выданные любым приложениям, можно посмотреть и отозвать на странице настроек безопасности Google: <https://security.google.com/settings/security/permissions>.

## 8. Ключ API

Ключ API принадлежит владельцу панели, хранится только на его компьютере и никому не передаётся.
